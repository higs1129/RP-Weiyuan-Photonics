# 独立产品验证记录

日期：2026-10-16。应用 0.3.0，公共库 0.2.24，Python 3.10 x64，PyRPL 0.9.8.0。

- 在含中文和空格的临时目录创建全新虚拟环境，全部 37 项依赖使用随附 wheels 安装，版本核对及 `pip check` 通过。
- Qt 离屏渲染及 Windows 原生平台插件渲染、网页资源和后台模块导入通过；实际导入路径位于独立环境的 site-packages，没有引用 D 盘原工作台源码。
- 27 项离线检查通过：RP/UART 连接诊断、配对边界、HV/LV 配置和原始数组不变、RF 增益/损耗核对、失锁重新获取参考及连续采集配合等。
- 浏览器离线检查通过：1366×768、1280×720、1920×1080 的页面核心内容、激光器侧栏、左键缩放、导航与实时数据保持坐标范围、手机布局；连接失败才显示诊断；标题和单位标识正常。所有仪器 API 均被拦截，没有真实设备调用。
- 更新实验通过：修改应用源码后复用原依赖环境；个人配置逐字保持；语法错误和非法配置均不切换有效版本。
- 回退恢复此前源码与匹配环境，重新更新可退出回退状态；诊断入口通过。
- 隔离启动器打开本地 HTTP 服务，`/api/info` 返回指定 RP 名称和应用版本，RP 与激光器均保持未连接；主页可读取。
- 从 Git 暂存索引导出完整目录，Windows PowerShell 5.1 启动、全部固定资源的 SHA256、依赖复用和应用验证通过；个人配置未进入导出目录，由首次启动生成。
- 原工作台 117 个公共设备、任务及其他流程源文件 SHA256 保持不变；其所有 Python 文件解析及剩余命令入口帮助通过。

验证脚本位于仓库外的临时目录。未执行真实仪器采集、锁定或激光器命令；分拆后的实机操作仍需在空闲实验时核对。发布版本和下载入口见项目 README.md。
