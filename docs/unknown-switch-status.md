# 0.3.13：TEC / LD 开关状态未知时继续调节参数

- 状态读取失败只将对应开关显示为“未知”，附带警告；模式、实际温度、电流及设定值仍可读回。
- 温度、电流按当前控制模式设置，保留写回响应、设定值读回、前后控制模式一致性验证。设置确认与开关状态确认相互独立。
- 开关未知时，“连接并启动”只建立激光器通信，不自动切换模式或开关 TEC / LD。原有能完整确认状态的设备仍沿用原启动流程。
- 任一必要数据寄存器读取失败仍报错；不能将网络故障、认证失败或设定失败显示成成功。
- 不解析未在当前协议中记录的 5 字节状态回复，不把未知状态当作关闭或开启。

公共库固定为 `a221-workbench 0.2.35.post1`，从原固定版本 0.2.35 增加可选部分状态读回，默认严格行为不变。依赖 wheel 和源码快照一同更新并核对 SHA256。

关闭平台后运行项目的 `update.cmd`，完成后再启动。此版本不需要重新部署 RP 上的 UART 服务。
