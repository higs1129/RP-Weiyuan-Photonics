# 0.3.14：按 TEC / LD 实际开关状态启动

点击“连接并启动”后：

1. 读取真实状态，支持现场确认的 5 字节短帧与原 8 字节长帧。
2. 沿用设备当前温度、电流设定，核对调试模式设定并进入调试模式。
3. TEC 已开启则保留；关闭则发送一次开启指令并等待确认。
4. TEC 确认开启后检查 LD；LD 已开启则保留，关闭才发送一次开启指令。
5. 开启后最多等待 5 秒、只读查询状态；确认后读取最终温度、电流和状态。超时或无效应答停止本次启动，不重复写入。

每分钟连接监测、“读取一次”和“仅验证激光器读回”都不自动开启输出。未知开关状态继续采用 0.3.13 的警告与参数调节方式，不猜测开关状态。

该自动启动会开启 LD 并可能出光；成功只表示模式与开关已读回确认，不代表温度已经到达目标，或实际电流与设定值完全一致。程序保留实际温度、电流显示，不自动把温度改为当前读数。

公共库版本为 0.2.35.post2。短帧是依据现场合法读回与状态变化确认的扩展，不是当前 V1.2 文档中列出的原长帧示例。无需重新部署 RP UART 服务。
