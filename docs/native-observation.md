# 0.3.6：PyRPL 原生观察与双游标

时域观察页保留激励设置，点击“打开 Scope 并连续观察”后在当前后台打开独立 PyRPL Scope 窗口。默认 CH1=ASG1、CH2=IN2，ASG1 内部同步触发；可选自由采集。频域观察同样打开当前后台的 Spectrum，默认观察 IN2。没有创建第二个 PyRPL 实例，网页不再轮询、传输或绘制这两页的波形。测量初始化保留网页波形。

单次 burst、周期 burst、连续波及常见波形仍在网页设置。输出必须明确点击；打开窗口不会开启激励。burst 自动采集时间窗沿用 frequency、cycles 的计算，可取消自动匹配来观察较慢响应。勾选“发送时在 PyRPL Scope 单次采集”会先武装原生 Scope，再发送一包。未勾选时保持观察与激励独立，暂停采集不会停止输出。等待 ASG1 事件时可长期等待，不使用网页单帧请求的 20 秒超时。

切到 PyRPL 窗口或隐藏浏览器会继续本次输出，由可见的原生 Scope 窗口维持激励租约。关闭原生窗口、离开时域功能页或正常退出平台会停止本次激励；窗口也有独立“停止激励输出”按钮。进程异常退出且原生窗口仍存在时，应使用这个按钮或关闭窗口停止输出；通信故障不能保证设备已经关闭。

## 手动测量 Δt

频谱初次打开默认显示 IN2 的 dBm/Hz，沿用 config.json 的负载、高阻与外部增益校正；不显示重复的第二路及互谱。之后可在原生界面选择其他单位，V 类单位不等同于经过射频链路校正的 dBm/Hz。

1. 获取一帧同时含 ASG1 和 IN2 响应的波形。
2. 点击“冻结当前波形测时”，放大相应区域。
3. 将 A 游标放到 ASG1 参考位置，B 游标放到 IN2 对应响应位置；需要时点击“游标移到当前视野”。
4. 读取 tA、tB 与 **Δt = tB − tA**，单位 μs。XY 模式下不提供时间差读数。

游标由用户定义对应位置，不自动判定响应阈值。ASG1 是内部数字信号，并非 OUT1 端口实测；读数包含未标定的 DAC/ADC、线缆及外部系统延迟，不能直接当作纯传播时间。内部事件也不保证每包首周期触发，周期 burst 的观察不保证逐包无遗漏。

## 与锁模、重锁共用采集资源

正常守护仍读取 IN1/PID0 状态，不占用 Scope 波形通道。初次锁模和失锁后重新获取锁点时，暂停原生观察，保存其真实参数、显示数据及运行/暂停状态，临时以 IN1/OUT2 扫描。窗口保留之前的响应图，不显示锁模扫描。

确认重新锁定后恢复原生参数和原运行状态；原来暂停的窗口不会自动连续运行。重锁中关闭窗口，之后不会重新打开。锁模失败时保持暂停，需处理错误或恢复扫频。重锁期间存在观察空隙，不是四路同步采集；激励本身不因重锁自动重发或更改波形。

公共依赖升级至 a221-workbench 0.2.31，新增 native_observation_revision=1。更新应用后，连接时沿用空闲后台身份检查；正在采集、输出或守护的后台不会被自动替换。旧后台需先停止相关操作再重新连接。

开发验证仅使用临时离线校验、PyRPL 假设备寄存器和浏览器桩接口；未执行真实测量。实际时序与模拟端口仍需现场回接验收。

## 0.3.7：初始化与重锁不继承原生平均次数

现场确认：时域 Scope 的 trace_average 改为 50 后，切回初始化、恢复扫频和获取锁点的旧代码没有复位此参数。PyRPL single() 会等待全部 50 次平均完成，造成约 0.2 帧/秒；锁点采集还可能超过 5 秒超时。常规 IN1 守护读取 sampler，不受网页帧率限制，但重新获取锁点需要 Scope，因此也受这项残留参数影响。

初始化预览（扫频和锁定后）、恢复扫频、初次锁模以及每次自动重锁现在使用同一个明确配置：先关闭 run_continuous，trace_average=1、average=True、rolling_mode=False、trigger_delay=0，时间窗由各功能自己的设置决定，通道和触发随模式切换。这里 trace_average 是完整帧平均次数；average 是硬件降采样平均，保留 PyRPL 默认 True，两者不同。不改变 PID 参数、锁点阈值、输出路由或标定，也不靠延长超时掩盖配置残留。

原生 Scope 的平均次数和其他观察参数仍保存于原生预设：重锁占用时临时切到单帧，重新锁定后恢复用户的 50 次设置；关闭后再次打开 Scope 也恢复其预设。公共库 0.2.32 将 trace_average、run_continuous、average 加入正式的 Scope 参数接口。

离线回归使用固定 PyRPL 的真实 single()/平均协程，每帧注入 100 ms 合成等待（不连接硬件）：旧配置 50 帧耗时 5.48 s、约 0.18 帧/秒，并复现参考超时；修复后初始化三种状态、恢复扫频、初次锁模和再次重锁均只执行一次采样，原生预设仍恢复为 50。另有 14 项守护/原生接口及 10 项既有激励/采集检查通过；中文路径独立环境离线安装成功。这些时间为离线复现结果，不是实机性能承诺。
