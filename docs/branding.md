# 微源仪器台单位标识

软件展示中国科学院物理研究所及其应用物理中心标识。单位关系由[物理所科研部门页面](https://www.iop.cas.cn/jgsz/kyxt/apc/)核对；该页链接到[应用物理中心官网](https://apc.iphy.ac.cn/)。

使用中心官网页脚的[官方组合标识原图](https://apc.iphy.ac.cn/images/dblogo.png)，其中同时包含物理所圆形所徽、应用物理中心蓝色图形及中英文名称。于 2026-10-16 获取，PNG / RGBA，原始尺寸 520×130；未重绘、裁切或改色，仅按原比例缩放显示。

本地文件：`src/rp_weiyuan/static/brand/iop-apc.png`。图片随软件包分发，显示时不请求外网；标识权利归相应单位所有。

宽屏在侧栏底部显示小版及可读单位名称，在仪器连接页标题旁显示较大版本；窄屏侧栏标识收进页面底部“关于本仪器台”。测量页不添加顶部大图，不改变设备操作和采集布局。
